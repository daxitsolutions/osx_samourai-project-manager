# Validation de l'issue #34 — 2 novembre 2026

## Périmètre

[Issue #34](https://github.com/daxitsolutions/osx_samourai-project-manager/issues/34) : empêcher les nouvelles saisies non sauvegardées après un échec de chargement.

Base : `989f7a89035f28e50997486de5f78bb16d91f653`, tête de la PR #60 encore ouverte. Les résultats ci-dessous portent sur cette base et les modifications non commitées de l'issue #34 : état de chargement explicite, protection des mutations, récupération dans l'interface, réessai et restauration avec conservation du fichier rejeté.

## Environnement

macOS 26.6.2, Apple Silicon, Apple Swift 6.4 (`swiftlang-6.4.0.34.1`). Compilation des modèles, stores et services modifiés dans un module métier temporaire, puis exécution des sources de tests avec Swift Testing.

Adaptations du banc : portions SwiftUI de `AppLocalization.swift` et `ImportProgressTracker.swift` exclues, `Bundle.module` lié au bundle du runner. Validation, chargement, mutations, migration et persistance utilisent le code du dépôt. Les tests créent uniquement des dossiers temporaires. Ce banc ne valide ni les écrans SwiftUI ni le bundle de traductions distribué.

## Exécution locale — 2 novembre 2026

Commandes exécutées après préparation du module temporaire :

```bash
swiftc -parse-as-library -swift-version 6 -enable-testing \
  -module-cache-path /tmp/samourai-audit-module-cache \
  -module-name SamouraiProjectManagerApp \
  -emit-module -emit-module-path /tmp/samourai-issue34-validation/SamouraiProjectManagerApp.swiftmodule \
  -emit-library /tmp/samourai-issue34-validation/Sources/*.swift \
  -o /tmp/samourai-issue34-validation/libSamouraiProjectManagerApp.dylib

env DYLD_LIBRARY_PATH=/Library/Developer/CommandLineTools/Library/Developer/usr/lib \
  /tmp/samourai-issue34-validation/store-tests
```

Résultat : **réussi**, codes de sortie **0**. **14 tests**, dont un test paramétré sur cinq catégories, soit **18 scénarios**.

| Test de récupération | Résultat constaté |
|---|---|
| `failedLoadBlocksMutationsEvenAfterDismissingTheAlert` | État de récupération persistant ; création refusée sans identifiant de succès ; remise à zéro refusée ; fichier inchangé après fermeture. |
| `APIAndImportsCannotBypassRecovery` | Écriture et remplacement API refusés avec statut 503 ; imports refusés ; aucun projet publié. |
| `retryOnTheSameStoreLoadsTheRepairedFile` | Le même store relit le fichier réparé, redevient prêt et peut sauvegarder. |
| `unsuccessfulRetryKeepsRecoveryActive` | Un nouveau chargement invalide garde l'édition bloquée et le fichier intact. |
| `restorePreservesRejectedBytesAndWritesBeforeUnlocking` | Copie exacte du fichier rejeté dans `recovery-backups`, base restaurée présente sur disque avant retour à l'état prêt. |
| `invalidRestoreDoesNotUnlockOrReplaceTheFile` | Une sauvegarde invalide ne modifie ni le fichier ni l'état de récupération. |
| `failedPreservationDoesNotUnlockOrOverwriteTheFile` | L'impossibilité de créer la copie de sécurité empêche la restauration et préserve l'original. |
| `failedRestoreWriteDoesNotUnlockEditing` | Un échec d'écriture garde l'édition bloquée sans publier les projets. |
| `failedLegacyMigrationCannotStartAnEmptyEditableDatabase` | Un échec de migration ne démarre pas une base vide modifiable et préserve le fichier legacy. |

Les cinq tests de `StoreLoadingTests` passent aussi : rejet des UUID dupliqués (cinq cas), normalisation des références orphelines, homonymes de livrables, sauvegarde dans l'emplacement injecté et validation des doublons imbriqués par restauration/API. L'assertion de `hasLoaded` suit désormais son sens explicite : vrai uniquement après un chargement ou une restauration réussis.

Preuve : [journal de réussite](2026-11-02-issue-34-loading.log).

Le binaire temporaire n'est pas distribué. La commande reproductible depuis un clone, avec une chaîne Xcode fonctionnelle, est `swift test --parallel`.

## Limites et checks CI

La commande locale suivante est **bloquée par l'environnement** : plugin `SwiftUIMacros.StateMacro` introuvable dans les Command Line Tools.

```bash
env CLANG_MODULE_CACHE_PATH=/tmp/samourai-issue32-module-cache \
  SWIFT_MODULECACHE_PATH=/tmp/samourai-issue32-module-cache \
  swift test --disable-sandbox --scratch-path /tmp/samourai-issue34-full
```

Les contrôles de compilation complète et de non-régression GitHub doivent être vérifiés sur le commit de la nouvelle PR. Le parcours visuel de l'écran de récupération est **non exécuté** localement ; les checks de compilation ne constituent pas un test GUI.
