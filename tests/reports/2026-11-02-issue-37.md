# Validation de l'issue #37 — 2 novembre 2026

## Périmètre

[Issue #37](https://github.com/daxitsolutions/osx_samourai-project-manager/issues/37) : une annulation ne doit pas laisser un import partiellement appliqué.

Base : `eae8879` (`main`). Commit de code testé : `aa3af30919f2d0732fb4eeea5ddd1370049e538b` (branche `codex/fix-37-atomic-import-cancel`).

Comportement retenu : **pas d'import partiel**. Les imports asynchrones de ressources (`ResourceStore.applyResourceImportReviewAsync`) et de risques (`SamouraiStore.importRisksAsync`) travaillent sur une copie de l'annuaire ou des projets/risques. La publication et la sauvegarde n'ont lieu qu'après une dernière vérification d'annulation, en finalisation. Une modification faite pendant l'import par une autre voie (API, autre vue) est conservée : l'import est alors refusé en bloc avec un conflit 409 et un message invitant à le relancer. L'import synchrone des risques utilise la même fonction d'ingestion sur copie.
