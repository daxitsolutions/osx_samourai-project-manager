# Validation de l'issue #38 — 2 novembre 2026

## Périmètre

[Issue #38](https://github.com/daxitsolutions/osx_samourai-project-manager/issues/38) : un même fichier peut créer plusieurs fois la même ressource.

Base : `d52acbe`, tête de la PR #65 (issue #37) encore ouverte, car les deux corrections modifient la boucle d'application de l'import. Commit de code testé : `b9b44e4172b7a0f79dbf11a5fd6d88b0a28c176c` (branche `codex/fix-38-resource-import-duplicates`).

Règle métier appliquée :

- Pendant la préparation du lot, les clés métier (nom + email, la clé de rapprochement existante) des lignes déjà traitées sont indexées.
- Une ligne de même clé qu'une ligne précédente ne crée pas de ressource : elle complète la ressource proposée par la première ligne (création ou mise à jour d'une ressource existante). La revue l'indique : « Doublon de la ligne N : les valeurs sont cumulées dans l'ordre du fichier. »
- Les lignes sont traitées par numéro de ligne, quel que soit l'ordre de lecture ; les dernières valeurs renseignées l'emportent (règle de fusion existante). Une ligne identique apparaît « Aucune modification ».
- Si la première ligne est décochée et un doublon coché, le doublon crée la ressource une seule fois.

Résultat : **réussi**, code de sortie **0** — `Test run with 25 tests in 5 suites passed`. Preuve : [journal](2026-11-02-issue-38-tests.log).

| Test `ResourceImportDuplicateTests` (chemins synchrone et asynchrone) | Comportement vérifié | Résultat |
|---|---|---|
| `identicalRowsCreateASingleResource` | Revue : création puis « Aucune modification » marquée doublon de la ligne 2 ; une seule ressource créée. | réussi (2 cas) |
| `laterRowsCompleteTheResourceCreatedByTheFirstRow` | Trois lignes : création, mise à jour, aucune modification, même identifiant ; téléphone final = dernière valeur renseignée. | réussi (2 cas) |
| `duplicateStillCreatesTheResourceWhenTheFirstRowIsDeclined` | Première ligne refusée : le doublon crée une ressource unique, avec ses valeurs. | réussi (2 cas) |
