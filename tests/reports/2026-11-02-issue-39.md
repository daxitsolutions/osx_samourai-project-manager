# Validation de l'issue #39 — 2 novembre 2026

## Périmètre

[Issue #39](https://github.com/daxitsolutions/osx_samourai-project-manager/issues/39) : limiter et protéger l'accès à l'API REST locale.

Base : `eae8879` (`main`). Commit de code testé : `7269739c2b5527ae341f283d02ce86ece936c744` (branche `codex/fix-39-rest-api-loopback`).

Changements :

- `RESTAPIAccessPolicy.makeListener` lie le listener à `127.0.0.1` (`requiredLocalEndpoint` + interface loopback) ; toute connexion dont le pair n'est pas en boucle locale est coupée.
- Avant routage, une requête est refusée en **403** si son en-tête `Host` n'est pas `localhost`, `127.0.0.1` ou `[::1]` (DNS rebinding) ou si son `Origin` n'est pas une page servie en local. Les écritures et suppressions ne sont donc plus accessibles depuis un site tiers.
- Plus de CORS `*` : seule l'origine locale validée est renvoyée, avec `Vary: Origin`. Les clients sans `Origin` (curl, scripts) restent acceptés.
- Plafonds : en-têtes 64 Kio (**431**), requête 32 Mio (**413**, y compris `Content-Length` annoncé), réception complète en 15 s (**408**). Une requête en cours de traitement n'est pas interrompue par le délai.
- L'URL affichée devient `http://127.0.0.1:<port>/api`.

Choix retenu : aucun mode réseau n'existe ; l'accès hors de la machine n'est donc plus possible, et l'authentification prévue par l'issue pour un tel mode est sans objet. Les processus locaux de la même machine restent des clients de confiance.

## Environnement

macOS 26.6.2, Apple Silicon, Apple Swift 6.4 (`swiftlang-6.4.0.34.1`), Command Line Tools. La chaîne Xcode complète n'est pas utilisable localement (licence non acceptée) et les Command Line Tools ne fournissent pas les macros SwiftUI.

Banc local : module métier compilé avec `swiftc` à partir de `Support/`, `Models/`, `App/AppState.swift` et `App/TableColumnConfiguration.swift`, sans `InspectorWindowSizingSupport.swift` (macros SwiftUI) ; `Bundle.module` remplacé par le bundle du runner. Ce banc ne valide ni la compilation complète de l'application ni son interface.
