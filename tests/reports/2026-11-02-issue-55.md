# Validation de l'issue #55 — 2 novembre 2026

## Périmètre

[Issue #55](https://github.com/daxitsolutions/osx_samourai-project-manager/issues/55) : déporter la lecture et l'analyse Merlin hors du thread UI.

Base : `e99e2e6` (`main`). Commit de code testé : `c7a87233d1497fdedf556a5637de4dafa8e08120` (branche `codex/fix-55-merlin-off-main`).

Changements :

- `MerlinProjectImportService.importProjectInBackground` (`@concurrent`) exécute la lecture et l'analyse XML ou SQLite hors du MainActor. L'appel est structuré : il hérite de l'annulation de la tâche d'import.
- `Task.checkCancellation()` entre les étapes lecture → analyse → rapprochement, dans la boucle des activités XML et après la requête SQLite principale. Le bouton « Annuler l'import » interrompt donc l'analyse en cours.
- `AppShellView.handleMerlinImport` attend cette fonction ; `store.importMerlinProject` reste appelé sur le MainActor (isolation du store inchangée).

## Environnement

macOS 26.6.2, Apple Silicon, Apple Swift 6.4 (`swiftlang-6.4.0.34.1`), Command Line Tools. Banc local identique à celui de l'[issue #39](2026-11-02-issue-39.md#environnement) : module métier compilé avec `swiftc`, sans l'interface SwiftUI. Fichiers XML générés dans le dossier temporaire. Ce banc ne valide ni la compilation complète de l'application ni son interface.

Depuis la racine du dépôt :

```bash
python3 tests/run-business-clt.py /tmp/samourai-pass55-recheck > /tmp/samourai-pass55-recheck.log 2>&1

swiftc -swift-version 6 -module-cache-path /private/tmp/samourai-pass55-smoke-cache Sources/SamouraiProjectManagerApp/Support/MerlinProjectImportService.swift tests/MerlinImportSmoke/main.swift -o /private/tmp/samourai-pass55-smoke && /private/tmp/samourai-pass55-smoke

DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build -c release --product SamouraiProjectManager
```

Le script [run-business-clt.py](../run-business-clt.py) contient les commandes `swiftc` complètes, les flags Swift 6, le plugin Swift Testing, les chemins CLT, le runner et la liste exacte des sources. Il copie ces sources dans le dossier temporaire fourni ; il retire uniquement l’extension SwiftUI d’AppLocalization et la feuille SwiftUI d’ImportProgressTracker, fournit `Bundle.module = .main` et exclut `RESTAPIAccessTests.swift`. Il n’exécute pas SwiftPM et ne valide pas l’application entière. Les tests utilisent les stockages temporaires prévus par leurs fixtures. Le nouveau test crée lui-même son schéma et ses 20 000 activités dans un paquet temporaire, supprimé à la fin ; aucune donnée utilisateur utilisée.

Adaptation constatée : une première compilation du smoke en partageant le cache sous l’alias `/tmp` a échoué (sortie 1, double définition de module Clang `/tmp` et `/private/tmp`). La commande ci-dessus utilise un cache distinct avec chemin canonique, puis la compilation **et** l’exécution ont réussi. Aucun changement de couverture ni de check CI.
